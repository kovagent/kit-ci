# REPLACE_KIT

REPLACE_ONE_LINER. Served from bundled parquet with on-demand fetch and a local cache. No API keys. Offline after the first query.

## Install

```toml
[dependencies]
REPLACE_KIT = "REPLACE_VERSION"
```

Until it is published to crates.io, depend on the repository directly:

```toml
REPLACE_KIT = { git = "https://github.com/userFRM/REPLACE_KIT" }
```
